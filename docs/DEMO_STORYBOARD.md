# 答辩展示动线

首页直接展示团队自演进和金融政策风洞两组原图。评委可点击图片查看大图，或从图片下方进入实验记录及业务工具。点击“进入实验”后，总览展示同一任务的验证完成度、执行成员和具体修改。讲解者通过“开始讲解”进入初轮协作，再查看前后对比、提示词修改、经验复用与三类实验。每个结果都来自选中的归档，运行按钮另起实验，截图入口用于回看已完成运行。

## 产品决策

- `rule/navigation-vs-action`：首页图片、大图和实验记录使用链接；两组图片直接可见，不必先在下拉框中选择。
- `rule/cover-reachable-states`：图集直接读取随代码发布的原图和来源清单，不依赖在线模型或实验库；某一组文件异常时，另一组仍可浏览。
- `rule/one-primary-action`：图集主操作为“进入实验”；总览主操作为“开始讲解”；重新运行是次操作，联网模式和规模放在运行设置中。
- `rule/smallest-intervention`：复用现有 CompetitionService、团队图、对照和经验库，不创建第二套演示数据。
- `rule/inline-before-modal`：工具详情、逐行差异、原始证据和成本就地展开，研究工具从主线中收起。
- `rule/structure-before-containers`：用标题、对齐和留白组织验证指标，减少堆叠卡片。
- `rule/cover-reachable-states`：保留空归档、损坏归档、模型失败、运行中、刷新恢复和离线查看状态。
- `rule/name-object-scope-consequence`：重新运行产生新实验；切换页面与截图不修改实验；模型调用记录只保存用量、内容哈希和配置，不保存密钥或隐藏推理。

界面实现沿用项目 Streamlit 组件与深色样式；文案按 humanizer-zh 清理。表述和数值由实际运行证据约束。

## 展示顺序

0. 图片演示：团队自演进实录 → 原 Civitas 金融风洞实录；点击“进入实验”。
1. 实验总览：验证完成度、规则评分、成员数量及改进后的团队。
2. 团队协作：初始分工、通信、真实审查遗漏。
3. 自演进 / 前后对比：同输入的配置与结果变化。
4. 自演进 / 提示词与工具：模型生成的提示词如何成为下一轮执行契约。
5. 自演进 / 经验复用：规划员实际引用哪些历史记录。
6. 三类实验：报告生成、数据分析、任务规划。
7. 研究工具 / 技术与复现：openJiuwen 调用位置与可下载证据包。

截图采用以上页面的真实浏览器渲染，原图和哈希清单保存在 `static/competition_gallery/`。截图清单记录实验编号、运行编号、模型和拍摄时间，展示页明确标注为已完成实验。

原 Civitas 的 8 张图片复用 `static/showcase_gallery/`，文件哈希与原仓库版本逐张核对。它们以“原 Civitas 项目截图”单列，未绑定到当前团队实验编号。
