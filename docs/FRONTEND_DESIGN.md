# 前端演示设计

本次重构以苹果产品网页为视觉参考，沿用启元品牌、既有导航名称和实验链接。视觉重心从密集截图列表改为首屏产品展示、分章节画廊和直接进入实验的入口。团队自演进图集采用完整设计案例的 8 张新版界面截图，金融政策风洞保留 8 张原项目截图；原真实实验截图另行保留。

- 字体：中文标题优先使用苹方，中等字重配合更舒展的字距与行距；英文和正文使用系统字体。“进化”以字重和亮度强调，手机说明文字按完整语义分行。
- 颜色：默认低亮度午夜蓝、墨青与深靛渐变，收敛背景光晕与玻璃反光；银白标题、蓝灰次级文字与低饱和蓝色链接。浅色外观使用雾蓝与浅青白渐变，页面跳转保留所选外观。
- 布局：桌面最大内容宽度 1320px，手机使用两行导航与单张画廊。
- 材质：导航、胶囊操作区、展示边框与全屏弹层采用 Liquid Glass 风格的网页近似实现，使用半透明底色、背景模糊、内侧高光和双层细边缘。按钮悬停时呈现短暂反光；图表和截图内容保持清晰。减少透明度或浏览器不支持模糊时使用实色背景。
- 内容：首屏接入三类已完成实验的协作拓扑，切换演进前后、查看新增角色和任务证据；下方配对呈现规则评分、角色数、工具调用、记录耗时与市场曲线。曲线支持悬停、键盘和触摸滑块逐点查看，并保留完整数值表。
- 技术页面：按用户提供的技术研究报告加入双平面架构图、五类策略折叠说明、三条证据链和计算分工；当前运行信息与证据下载继续保留。报告与实现的对应关系见 `docs/TECHNICAL_CONTENT.md`。
- 交互：案例标签支持方向键 / Home / End，角色可选择查看职责。原图支持全屏查看、细节缩放、左右切换、方向键 / Home / End、手动启用自动播放、Escape 关闭弹层。
- 动效：首屏淡入、支持浏览器中的滚动显现；减少动态效果设置下禁用动画。自动播放不会自行启动，离开画廊或页面不可见时暂停。
- 数据：截图通过各自的清单校验，首页交互图从 `ExperimentArchive` 读取经过哈希和评分复算校验的记录。真实曲线使用原始数据点与共同坐标范围；政策收益差为零、干预风险改善为零及历史回放的条件假设均保留。独立设计案例明确标注“示例数据”，不混入真实档案。档案不可用时退回本地截图演示，不调用模型或启动实验。
- 完整案例：`ui/evolution_case.py` 提供 8 个可切换场景，覆盖任务、执行、反馈、策略、团队、复评、发布和复用；独立样式与交互位于 `theme/evolution_case.css` 和 `static/evolution_case.js`。案例讲解稿见 [自演进演示案例](自演进演示案例.md)。

样式统一位于 `theme/presentation.css`，首页渲染位于 `ui/demo_gallery.py`，数据可视化适配位于 `ui/showcase_visuals.py`，渐进交互位于 `static/presentation.js`。实验图与图表通过 `ui/appearance.py` 和 `ui/chart_theme.py` 适配外观。

启动方式保持 `streamlit run app.py`。本次本地预览使用 8503 端口。
